# 🎵 Music Player

## 📌 Description
A simple keyboard-controlled music player built with Pygame. It supports playlist navigation and basic playback controls.

## 🎯 Features
- Play / Stop / Next / Previous tracks
- Keyboard controls
- Playlist management
- Track information display
- Audio playback using Pygame mixer

## 🎹 Controls
- **P** → Play
- **S** → Stop
- **N** → Next track
- **B** → Previous track
- **Q** → Quit

## 🧠 How it works
- Audio files are loaded using `pygame.mixer`
- Playlist is stored as a list
- Current track index is tracked
- Keyboard input controls playback

## 🛠 Technologies
- Python
- Pygame

## ▶️ How to run
```bash
pip install pygame
python main.py
