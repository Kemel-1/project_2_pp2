# Pygame Practice 10

This project contains three simple applications built using Pygame: Racer, Snake, and Paint. Each program extends basic examples and adds new functionality.

## Requirements

* Python 3
* Pygame library

Install Pygame:
pip install pygame

## Run

python racer.py
python snake.py
python paint.py

## Racer

A simple racing game where the player avoids obstacles.

Added features:

* Randomly appearing coins
* Coin counter displayed on the screen
* Commented code

## Snake

Classic snake game.

Added features:

* Wall collision detection
* Food spawns randomly (not on snake or walls)
* Levels system
* Increasing speed with levels
* Score and level counter
* Commented code

## Paint

Basic drawing application.

Added features:

* Draw rectangles
* Draw circles
* Eraser tool
* Color selection
* Commented code
